🚀 Cara Menggunakan Logo di HTML

Ada 3 cara untuk menggunakan file SVG di HTML:

  • Sebagai Image Tag:
<img src="assets/logo_travelgo.svg" alt="Logo TravelGo" width="200">
  • Sebagai Background CSS:
.header { background-image: url('assets/wallpaper_travelgo.svg'); background-size: cover; background-position: center; }
  • Inline SVG (untuk styling lebih fleksibel):
<div class="logo"> <svg>...</svg> </div>

🖼️ Mengkonversi SVG ke PNG/JPG

Jika Anda memerlukan format PNG atau JPG, gunakan salah satu metode berikut:

  • Online Tools: CloudConvert, Convertio, atau Online-Convert
  • ImageMagick (Command Line):
convert -density 300 argo_bromo.svg -quality 95 argo_bromo.png
  • Inkscape (Desktop App): Open SVG → Export As → PNG/JPG
  • Python Script:
# Menggunakan cairosvg library pip install cairosvg cairosvg argo_bromo.svg -o argo_bromo.png

🎨 Responsive Logo Implementation

Untuk membuat logo responsif di berbagai ukuran layar:

<img src="assets/logo_travelgo.svg" alt="Logo TravelGo" class="logo-responsive"> <style> .logo-responsive { max-width: 100%; height: auto; width: 150px; /* default */ } @media (max-width: 768px) { .logo-responsive { width: 100px; } } </style>
💡 Tips: SVG adalah format terbaik untuk web karena:
  • Scalable tanpa kehilangan kualitas
  • Ukuran file lebih kecil dibanding PNG/JPG
  • Bisa diubah warna dengan CSS
  • Bisa dianimasikan dengan CSS/JavaScript
